# Sumber data

Su, Z. (2023). *Temporal dynamics in psychological assessments: a novel dataset with scales and response times*
[Data set]. Zenodo. https://zenodo.org/records/10423537 — lisensi **CC BY 4.0**.

File yang dipakai: `phq9.csv`, `gad7.csv`, `demographic.csv` (24.292 mahasiswa, dikumpulkan 27 Feb–17 Mar 2021).
Kolom `questionN` = jawaban item (0–3), `timeN` = waktu menjawab item (detik), `score` = total.
File tidak diubah dari aslinya.
